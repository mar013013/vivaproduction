# VIVA ONE

VIVA ONE — мобильная персональная операционная система для задач, целей, личных финансов и заметок.

## GitHub-версия

- адаптивный премиальный интерфейс для телефона и компьютера;
- задачи с приоритетами, сроками и отметкой выполнения;
- цели с прогрессом;
- доходы, расходы и текущий баланс;
- заметки;
- локальное сохранение данных на устройстве;
- тёмная и светлая темы;
- PWA-манифест и базовый офлайн-режим;
- запуск без сборки и внешних зависимостей.

## Расширенная ZIP-версия

Расширенная сборка дополнительно содержит привычки, серии, фокус-таймер 25/5, умные подсказки по текущему дню, поиск и фильтры задач, категории расходов, экспорт и импорт резервной копии.

## Локальный запуск

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080/viva-one/`, если сервер запущен из корня репозитория, либо `http://localhost:8080/`, если сервер запущен непосредственно из папки `viva-one`.

## Публикация

Для публичного адреса необходимо включить GitHub Pages для репозитория или разместить папку `viva-one` на любом статическом хостинге.
