# VIVA ONE

VIVA ONE — мобильная персональная операционная система: задачи, цели, привычки, заметки, финансы, фокус-таймер и локальные умные подсказки.

## Что уже работает

- адаптивный премиальный интерфейс для телефона и компьютера;
- задачи с приоритетами, сроками, фильтрами и поиском;
- привычки и серии;
- цели с прогрессом и сроками;
- доходы, расходы, баланс и категории;
- заметки;
- Pomodoro 25/5 и учёт фокус-времени;
- локальные рекомендации на основе текущих данных;
- тёмная и светлая темы;
- экспорт и импорт резервной копии;
- PWA-установка на телефон;
- офлайн-режим;
- все данные хранятся только на устройстве пользователя.

## Запуск

Проект не требует сборки и зависимостей.

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`.

## Публикация на GitHub Pages

1. Загрузить файлы в отдельный репозиторий.
2. Открыть **Settings → Pages**.
3. Выбрать **Deploy from a branch**, ветка `main`, папка `/root`.
