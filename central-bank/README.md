# CENTRAL BANK · Personal Wallet

Личная визуализация капитала Марата Мнацаканяна в стиле Wallet. Все средства и продукты вымышленные, банковские услуги не оказываются.

## Запуск

Из `/workspace/vivaproduction`:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Путь приложения на сервере: `/central-bank/`. Зависимости, сборка, ключи API и база данных не нужны. Все ресурсы локальные. Для сохранения данных и работы идентификаторов используйте HTTP на localhost или HTTPS.

## Разделы

Навигация меняет URL (`#accounts`, `#payments` и т. д.), поддерживает прямые ссылки, обновление страницы и историю браузера.

- Обзор: доступные счета, последние операции и сводка капитала.
- Счета и карты: RUB Mastercard и USD Visa, заморозка и дневные лимиты карточных платежей.
- Переводы и платежи: локальные переводы, обмен валют, связь, услуги, покупки и пополнение.
- Вклады: открытие на 3/6/12 месяцев, расчёт дохода, закрытие с возвратом средств.
- Инвестиции: три вымышленных инструмента, покупка и продажа по фиксированным ценам.
- Активы: счета, вклады, портфель, недвижимость и автомобиль; ручное добавление/редактирование имущества и финансовая цель.
- Кредиты: существующий кредит, аннуитетный калькулятор, зачисление нового кредита и погашение основного долга.
- Страхование: добавление условных программ со списанием годовой стоимости, просмотр условий.
- История: поиск, фильтр поступлений/списаний, до 300 локальных записей.
- Настройки: скрытие сумм, уведомления, сброс всех данных с подтверждением.

Общий баланс на главной включает только доступные счета. Чистый капитал дополнительно учитывает вклады, портфель и имущество за вычетом долга. Открытие вклада/покупка активов не создаёт новый капитал, а перемещает средства между категориями. Имущество не пополняет счета. Кредит одновременно увеличивает счёт и долг.

Расчётный курс фиксирован: 95 ₽ за доллар; комиссии отсутствуют. График декоративный. Вклады используют простые проценты без капитализации: при досрочном закрытии возвращается основная сумма, по окончании срока — с расчётными процентами. Кредитные проценты автоматически не начисляются; погашение уменьшает основной долг. Страховые программы не создают настоящих полисов.

Данные хранятся в localStorage (`central-bank-wallet-v2`) текущего браузера. При первом открытии обновлённой версии прежние RUB/USD балансы переносятся из `central-bank-demo-v1`. Изменения не синхронизируются между устройствами. Сброс возвращает 125 млн ₽ и 2,5 млн $, вклад 20 млн ₽, портфель 14,9 млн ₽, имущество 103 млн ₽ и кредит 1,5 млн ₽.

## Публикация и автономный файл

GitHub Actions собирает общий Pages-артефакт: существующий `wedding-budget` остаётся в корне сайта, CENTRAL BANK размещается в `/central-bank/`. Два существующих workflow используют одинаковую структуру, чтобы повторная публикация свадебного приложения не удаляла Wallet.

Команда `python3 central-bank/export.py /tmp/central-bank.html` из корня репозитория создаёт один HTML-файл со встроенными стилями и JavaScript. В Pages-артефакте он доступен как `/central-bank/central-bank.html`. Для просмотра на телефоне предпочтителен опубликованный HTTPS-сайт: встроенные просмотровщики скачанных HTML-файлов могут блокировать JavaScript.
