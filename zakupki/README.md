# Фруктодар — Закупки

Мобильное PWA-приложение для закупщика: цветные кружки поставщиков, быстрое добавление списка, отметка «куплено», архив, поиск, фильтры, голосовой ввод и офлайн-работа.

## Цвета

- 🔴 Яма — местное
- 🟢 Хутор Ленина — импортное
- 🟡 Орехи и сухофрукты
- 🟣 Лента / Ашан / Магнит / гипермаркеты

## Запуск

Откройте `index.html` через любой статический сервер. Для PWA и офлайн-режима нужен HTTPS или localhost.
