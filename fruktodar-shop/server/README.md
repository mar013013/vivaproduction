# Истории Фруктодара: сервер

Сервер реально хранит общие для всех покупателей истории. GitHub Pages не исполняет Python и не принимает загрузки, поэтому для работы нужен отдельный хостинг с HTTPS или перенос магазина на сервер.

## Проверенный локальный запуск

Требования: Python 3.11+, FFmpeg и ffprobe в PATH. Python-пакеты устанавливать не нужно.

В переменных процесса задайте:

- `STORIES_ADMIN_TOKEN`: случайный секрет длиной от 32 символов. Значение задаётся в защищённых настройках хостинга, не в исходниках, чате или браузерном config.js.
- `STORIES_DATA_DIR`: постоянная директория для SQLite и медиа вне публичного каталога сайта. Значение по умолчанию `/tmp/fruktodar-stories` подходит только для разработки.
- `HOST`: по умолчанию `127.0.0.1`.
- `PORT`: по умолчанию `8011`.
- `STORIES_ALLOWED_ORIGIN`: точный HTTPS-origin витрины, если API размещён отдельно, например `https://mar013013.github.io`. При размещении витрины и API вместе не нужен.

Из корня репозитория:

```sh
python3 fruktodar-shop/server/server.py
```

Сервер отдаёт витрину и панель `/fruktodar-shop/admin.html`. На боевом хостинге нужны reverse proxy с TLS, ограничение тела запроса 25 МБ, управление процессом и постоянный диск с резервным копированием. Временное рабочее окружение Codex не является производственным хостингом.

Для отдельного API укажите его адрес с завершающим слешем в `stories-config.js`: `https://your-host.example/api/stories/`. Секрет в этот файл не добавлять. В панели владелец вводит ключ, который остаётся только в памяти страницы; выход или перезагрузка требуют повторного ввода.

## Поведение

- Только авторизованный владелец может добавлять/удалять истории.
- Публичный API отдаёт активные истории без ключа.
- Поддерживаются JPG, PNG, WebP, MP4, MOV и WebM до 25 МБ.
- Сервер проверяет фактическое содержимое через ffprobe, видео длиннее 15 секунд отклоняет.
- Изображения нормализуются в JPEG с удалением метаданных; видео — в MP4/H.264/AAC до 1080px по ширине.
- Срок жизни: ровно 86400 секунд от успешной загрузки по серверным часам.
- Просроченные истории немедленно исключаются из выдачи; прямые запросы медиа тоже возвращают 404. Фоновая очистка удаляет их с диска и из SQLite раз в минуту.
- Поддерживаются byte-range запросы видео для Safari.
- База и файлы конфигурации не обслуживаются как публичные статические файлы.

Без API витрина показывает редакционные примеры подборок. Они не выдаются за загруженные владельцем суточные публикации. Панель прямо сообщает, что сервер не подключён; ложного сообщения об успешной загрузке нет.

Это первая рабочая серверная версия для небольшого магазина. Перед масштабированием нужны выбор хостинга, резервные копии, наблюдение за процессом и отдельная система учётных записей вместо общего ключа владельца.
