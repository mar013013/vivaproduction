# Фруктодар · розничный магазин

Первая отдельная версия витрины для Fruktodar.ru: Краснодар, контакт +7 918 390-13-13. Жёлто-зелёное оформление; настоящий логотип пока не предоставлен, используется временное текстовое название.

## Запуск

Из `/workspace/vivaproduction`:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Путь сайта на сервере: `/fruktodar-shop/`. Зависимости, сборка, внешние API и шрифты не нужны. Все ресурсы локальные. HTTPS нужен для удобного копирования заказа; при недоступности Clipboard API выводится текст для ручного копирования.

## Возможности

Категории корзин, наборов, фруктов/ягод, экзотики и акций; поиск; сортировка; избранное; карточка товара; корзина с изменением количества и расчётом стоимости; сохранение корзины и избранного в localStorage; подготовка и копирование состава заказа; контакт по телефону; FAQ; мобильная версия.

Цены, ассортимент, веса и предложения — примерные, требуют согласования с владельцем. Фотографии созданы для концепта, не являются фотографиями реальных партий. Отдельные варианты используют общую иллюстрацию. Публичных отзывов, подтверждений наличия и вымышленных обещаний о доставке нет.

Оформление не отправляет персональные данные и не создаёт принятого заказа. Клиент копирует состав и звонит для подтверждения наличия, цены и получения. Онлайн-оплата, учёт остатков, серверное принятие заказов и аналитика не подключены. Условия и стоимость доставки не заданы. Перед промышленным запуском нужны реальные карточки товаров, логотип, юридические данные магазина, условия торговли и согласованный канал приёма заказов.

Текущий Fruktodar.ru и DNS не менялись. Подготовлена публикация отдельного предпросмотра в `/fruktodar-shop/` через существующие GitHub Pages workflows. Публичная публикация этой версии пока не выполнялась; существующие проекты сохранены.
