# Фруктодар · социальная витрина

Отдельный вариант дизайна; публикация предпросмотра разрешена владельцем. Текущий `fruktodar-shop` не изменяется. Возврат к прежнему варианту — переход в соседний каталог; не нужны сброс, изменение домена или перенос данных.

Лента по мотивам социальной сети: собственное рукописное название «Fruktodar» шрифтом Grand Hotel, истории, большие публикации товаров, сохранёнки и плавающая стеклянная нижняя панель с пятью разделами. Название, символика и контент принадлежат магазину; логотип Instagram не используется. Шрифт сохранён локально из Google Fonts с лицензией SIL OFL.

## Запуск

Из `/workspace/vivaproduction`: `python3 -m http.server 8000 --bind 127.0.0.1`. Путь варианта: `/fruktodar-social/`. Зависимости и сборка не нужны. Для предпросмотра нужно обслуживать оба соседних каталога: реальные фотографии берутся из `../fruktodar-shop/assets/real/`, снимок каталога — локальный `catalog.json`.

## Работает

- Лента 12 настоящих товаров: фотографии из скриншотов, цены, подробности и составы двух наборов.
- Нижнее меню: лента, товарные истории, корзина, поиск и профиль.
- Истории по 15 секунд с прогрессом, паузой, навигацией и открытием товара; просмотренные отмечаются на этом устройстве.
- Поиск по названиям и составам, категории и сетка 3 колонки.
- Избранное, корзина, изменение количества, расчёт стоимости.
- Подготовка и копирование заказа, звонок для согласования.
- Прямые ссылки на товары через `#product/ID` и системная отправка ссылки/копирование.
- Общий с обычным магазином localStorage `fruktodar-store-v1`: корзина и сохранёнки переходят между двумя дизайнами.

Это визуальный прототип, а не новая соцсеть: подписки, комментарии, аккаунты, онлайн-оплата и приём заказов сервером не добавлены. Числа просмотров/подписчиков и уведомления не выдумываются. Второй раздел показывает фотоистории, а не изображает несуществующие видеоролики. Товарные истории постоянные; подключение серверных суточных историй возможно отдельно после выбора хостинга. Роли владельца и покупателя не смешаны: плюс в шапке открывает подборку подарков, а не общедоступную загрузку медиа.

SEO-страницы товаров не заменяются этим экспериментом. Пока вариант помечен `noindex,nofollow` и публикуется только как отдельный предпросмотр `/fruktodar-social/`. Данные каталога перенесены по скриншотам, актуальность цены/наличия подтверждает магазин. Профиль показывает реальные локальные сохранёнки и корзину, не имитирует серверный вход и оплаченные заказы.


## Монохромный вариант и жесты

Верхнее название — Fruktodar латиницей. Интерфейс переведён на белый/чёрный/нейтральный серый, кольца историй — розово-оранжевый градиент, лайк — красный, закладка — чёрная. Основной текст использует системный sans-serif (на iPhone системный SF); точное совпадение проприетарного логотипа/шрифтов Instagram не заявляется.

Двойное нажатие на фотографию сохраняет товар в избранное с анимацией белого сердца. Повторный двойной тап не снимает сохранение. Одиночный тап по фото ничего не открывает, чтобы не мешать жесту; подробности доступны по названию, кнопке «Подробнее», многоточию, а с клавиатуры — Enter на фото. Прокрутка/перетаскивание не считаются лайком. Обычное нажатие сердечка переключает сохранение.

Стрелка пересылки вызывает Web Share API и передаёт название, цену и прямую ссылку `#product/ID`. Получателя выбирает пользователь в системном меню. При отсутствии Web Share ссылка копируется; если Clipboard API недоступен, выводится текст для ручного копирования. Для открытия ссылки другими людьми сам отдельный вариант должен быть опубликован. Публикация отдельного варианта разрешена владельцем; обычный магазин остаётся на своём адресе.
