# Fruktodar AI

Мобильная PWA для закупок магазина Fruktodar.

## Что работает

- голосовой ввод через Web Speech API (`SpeechRecognition` / `webkitSpeechRecognition`);
- разбор свободного русского текста по базам, цветам кружков, количеству и цене;
- базы по умолчанию: Яма, Хутор, Гарант, Фруктодар, Апельсинка;
- ручное редактирование, статусы «куплено / не куплено» и фильтры;
- обучаемая локальная память: после ручной смены базы приложение запоминает товар;
- отправка списка через Web Share API или копирование в буфер;
- локальный ассистент для подсчёта позиций, суммы, прогресса и фильтрации;
- генератор печатных ценников строго 58 × 40 мм, один ценник на страницу;
- PWA, офлайн-кэш, экспорт и импорт данных.

## Важно об AI

Текущая версия использует локальный интеллектуальный парсер и работает без API-ключа. Для подключения облачной языковой модели нужен защищённый серверный endpoint: API-ключ нельзя безопасно хранить в браузерном JavaScript.

## Запуск

Откройте `index.html` через HTTPS-сервер. На GitHub Pages приложение работает из папки `/fruktodar-ai/`.

## Основа интерфейса

Визуальная и компонентная структура спроектирована с ориентацией на современные open-source dashboard-паттерны, включая MIT-проект `Kiranism/next-shadcn-dashboard-starter`. Код приложения написан отдельно как статическая PWA, чтобы работать на GitHub Pages без сборщика и сервера.
